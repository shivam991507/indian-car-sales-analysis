# Raw data

The original dataset is sourced from Kaggle:

https://www.kaggle.com/datasets/subhadeeptasahoo/car-sales-in-india-20192021

For a fully reproducible run, download the CSV and save it in this folder as:

`car_sales_india_2019_2021.csv`

The public repository intentionally does not redistribute the original Kaggle file because the dataset license could not be verified during repository preparation. The processed 2019 and 2021 tables used in the analysis are available in `../processed/`.
