# Original academic report

`original_academic_report.pdf` is the original undergraduate project report submitted for the Statistics project.

It is included to preserve the original project presentation, tables, interpretations, calculations, charts and appendix code that formed the basis of the resume project description.

The repository also contains a later reproducible reconstruction from the supplied Kaggle CSV. During that reconstruction, a few manual/transcription differences were found in the report. Those checks are documented separately in `docs/data_quality_notes.md`; the original PDF itself is intentionally left unchanged.
